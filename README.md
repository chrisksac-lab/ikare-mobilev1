# iKare Mobile

Mobile healthcare application connecting patients with healthcare professionals through secure online consultations.

## Overview

iKare Mobile enables patients to access healthcare services remotely from their smartphones.

Users can book appointments, consult healthcare providers, receive medical recommendations, and manage their healthcare journey from anywhere.

## Key Features

- Patient registration and authentication
- Doctor discovery
- Appointment booking
- Online consultations
- Medical history access
- Notifications and reminders
- Secure profile management
- Healthcare recommendations
- Disease prediction support

## Technology Stack

- React Native
- React Navigation

## Screens

- Authentication
- Home Dashboard
- Appointments
- Consultation
- Medical Records
- Profile Management
